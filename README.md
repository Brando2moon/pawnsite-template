# Northline Pawn & Exchange — Website Template

A buyer-focused pawn-shop website template that lets customers browse current in-store inventory before visiting the store.

## Customer Experience

- Browse products currently carried by the store
- See actual prices, photos, condition, descriptions, and availability
- Search and filter inventory
- View firearm information and learn about the in-store special-order kiosk
- Find store hours, location, and contact information
- Purchase products and complete pawn services in person

## Store Features

- Product and photo management through a staff admin page
- Inventory statuses for available, reserved, sold, and archived products
- In-store kiosk mode for special-order firearm build quotes
- Confirmed-compatible component filtering with optional staff review
- Customer quote collection with name, phone number, and email
- Background-check status tracking performed by authorized staff in the store's existing system
- Prepared connection points for future manufacturer or distributor catalog APIs

This template is designed as a product catalog and in-store service tool. It does not provide online pawn loans, online firearm transfers, or public online checkout.
