# Northline Pawn & Exchange — Website Template

A professional pawn-shop website template built to connect the store owner with customers who want to buy, sell, or pawn items.

## For the Seller

- Showcase available inventory with photos, prices, condition, and descriptions
- Add and manage products from an admin dashboard
- Organize inventory by category and availability
- Receive sell-or-pawn appraisal requests from customers
- Receive customer messages and regulated-item inquiries
- Manage regular merchandise separately from inquiry-only items
- Present store information, hours, location, and contact details

## For the Buyer

- Browse jewelry, gaming systems, electronics, tools, musical equipment, accessories, and more
- Search, filter, and sort available products
- View product photos, prices, condition, and item details
- Save favorite products
- Add eligible products to a shopping cart
- Submit an item for a sell-or-pawn estimate
- Contact the store with questions or firearm inquiries
- Complete checkout for approved regular merchandise

## Website Features

- Professional deep-navy and gray design
- Mobile, tablet, and desktop responsive layout
- Homepage with featured inventory and service information
- Searchable online shop
- Product detail views
- Sell-or-pawn request form
- Separate firearm inquiry page
- Shopping cart and checkout pages
- About and contact pages
- Seller admin dashboard
- GitHub Pages deployment

This template can be customized with the pawn shop’s name, logo, inventory, contact information, payment system, and business policies.
